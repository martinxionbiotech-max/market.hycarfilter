# Hycarfilter Market Insights — Automotive Filter Industry Report

> **Positioning**: This sub-site is the "searched and cited **industry report layer**" — global market / regional demand / industry trends / purchasing guide / industry data reference.
> Zero overlap with the main site's marketing, and no overlap with the data site's product values or the tech site's process standards: **the data site manages "what are this model's parameters", the tech site manages "how to test and on what basis", and this repo manages "how big this industry is and how to sell it in which market".**

## Four-layer interlinking structure

```
hycarfilter.com        (Astro commercial main site)   → persuades buyers "why to buy"
data.hycarfilter.com   (MkDocs product database) → the single source of truth for models/specs "what the parameters are"
tech.hycarfilter.com   (MkDocs technical standards)   → "how to do it / how to test / on what basis"
market.hycarfilter.com (MkDocs industry report)   → this repo "how to sell this model in which market"
```

Interlinking rules: main site product pages → data model details → tech corresponding process/inspection pages → **this repo's regional reports**. Every page in this repo links back to the data site and tech site at the top, ensuring that the path "a buyer clicks from an industry report into specs and processes" is never broken.

## Source attribution labeling standard

All content in this repo follows a single labeling discipline: every page states it in a note at the top, and the body uses inline tags to distinguish:

- **[Industry Knowledge]** — common practices and public consensus in the filter industry, not bound by any single manufacturer;
- **[Framework Reference]** — introductions to certification / market entry / compliance frameworks (EAC / GCC / INMETRO / CE / REACH / RoHS etc.), **serving only as common-knowledge frameworks, not constituting certification or legal conclusions**;
- **[Data Citation]** — citing values identical to the [data.hycarfilter](https://data.hycarfilter.com) canonical dataset (HS codes / efficiency grades / certification fields etc.);
- **[Analytical Judgment]** — the researcher's original subjective judgment, attributed to "Xiaozhu ✍️", for reference in purchasing decisions.

> **Estimated data**: Market size ranges, growth rates etc. are **estimated references (for reference only)**, not authoritative statistics, serving only for order-of-magnitude reference and not as a basis for investment or purchasing/pricing decisions.

## Data-consistency statement

All **HS codes / efficiency grades / certification fields / category divisions** cited in this repo are identical in value to the canonical dataset `data/products.json` (v0.1.0) of [data.hycarfilter](https://data.hycarfilter.com); any product value is subject to the data site as the single source of truth. This repo is only responsible for "industry and market knowledge" and does not duplicate product values.
