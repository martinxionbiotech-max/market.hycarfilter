# 电动化对滤清器需求的影响

!!! note "来源性质"
    本文为编辑原创整合。**[行业常识]** = 行业通用做法；**[数据引用]** = 引用 [data.hycarfilter](https://data.hycarfilter.com) 同值；**[分析判断]** = 研究员原创判断（小筑 ✍️）。渗透率等趋势性数据为**估算参考 / for reference only**。回链：[售后市场 vs OEM](aftermarket-vs-oem.md)。

## 一、一个常见误读：电车不要滤清器

**[分析判断]** 很多人以为「电动车没有发动机，所以不用滤清器」。这个判断**对了一半，错了一半**：

- **对的一半**：纯电动（BEV）没有内燃机，因此**没有机油滤清器、没有燃油滤清器、也没有发动机进气空气滤清器**——这三类会随电动化长期下行。
- **错的一半**：电动车**仍然需要空调滤清器（座舱滤）**，而且电动车对「车内空气质量」的诉求往往比燃油车更强——因为电车的「安静」让异味、粉尘、颗粒更易被感知。

## 二、电动化对七类滤清器的差异化影响

**[行业常识]** 按动力形式（内燃机 ICE / 混动 HEV / 增程 REEV / 纯电 BEV）拆解需求：

| 品类 | ICE | HEV/REEV（带内燃机） | BEV（纯电） | 长期趋势 |
|---|---|---|---|---|
| 空气滤（发动机进气） | 需要 | 需要 | **无** | 长期下行 |
| 机油滤 | 需要 | 需要 | **无** | 长期下行 |
| 燃油滤 | 需要 | 需要 | **无** | 长期下行 |
| 空调滤（座舱） | 需要 | 需要 | **需要（且更重要）** | **长期向上** |
| 变速箱滤网 | 需要 | 需要 | 部分（减速器润滑） | 结构变化 |
| 雨刮 | 需要 | 需要 | 需要 | 不变 |
| LED 车灯 | 需要 | 需要 | 需要 | 不变 |

**[数据引用]** hycarfilter 的 7 大品类中，**空调滤、雨刮、LED 车灯**三类「与动力形式弱相关」，是电动化时代的「抗跌品类」；机滤、燃油滤、发动机空滤是「承压品类」——品类划分与 [data.hycarfilter](https://data.hycarfilter.com) 同值。

## 三、电动化的「反直觉增量」

**[分析判断]** 电动化对滤清器行业并非纯利空，有几个**反直觉的增量**：

1. **空调滤升级**：电车对座舱空气质量的敏感度更高，HEPA 级空调滤、活性炭滤的渗透率上升，**单价与毛利更好**；
2. **混动/增程的过渡期红利**：HEV/REEV 仍带内燃机，机滤/燃油滤/空滤需求在**过渡期（可能 10 年以上）依然存在**；
3. **电池热管理相关过滤**：部分冷却液/油液过滤需求是新品类机会（框架性观察，非本站产品范围）。

## 四、对采购者与供应商的建议

**[分析判断]**

1. **别恐慌抛售机滤/燃油滤**：全球内燃机 + 混动/增程的存量与增量，让这三类的需求在**中短期（10 年级）依然可观**，只是长期曲线向下。
2. **提前加码空调滤**：把空调滤从「附属品类」升级为「战略品类」——它是电动化时代**唯一确定向上**的滤清器品类，且附加值高（HEPA/活性炭）。
3. **用「抗跌组合」对冲**：空调滤 + 雨刮 + LED 车灯 + 变速箱滤网，是抗电动化冲击的品类组合；把资源向这里倾斜。
4. **盯住混动/增程市场**：在中国与部分新兴市场，混动/增程渗透快，其「带内燃机」的特性为传统滤清器**续了很长的命**。
