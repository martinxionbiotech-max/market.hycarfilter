# Hycarfilter Market Insights — 汽车滤清器行业报告

> **定位**：本子站是「被检索、被引用的**行业报告层**」——全球市场 / 区域需求 / 行业趋势 / 采购指南 / 行业数据参考。
> 与主站营销零重复、与 data 站产品数值、tech 站工艺标准**不重叠**：**data 站管「这个型号参数是多少」，tech 站管「怎么测、凭什么」，本仓管「这个行业多大、这个市场怎么卖」。**

## 四层互链结构

```
hycarfilter.com        (Astro 商业主站)   → 说服采购者「为什么要买」
data.hycarfilter.com   (MkDocs 产品数据库) → 型号/规格唯一真值「参数是多少」
tech.hycarfilter.com   (MkDocs 技术标准)   → 「怎么做 / 怎么测 / 凭什么」
market.hycarfilter.com (MkDocs 行业报告)   → 本仓「这款在哪个市场怎么卖」
```

互链规则：主站产品页 → data 型号详情 → tech 对应工艺/检测页 → **本仓区域报告**。本仓每页顶部回链 data 站与 tech 站，保证「采购者从行业报告点进规格与工艺」的路径不断。

## 来源性质标注规范

本仓所有内容遵守一条标注纪律，每页顶部以 note 声明，正文以行内标签区分：

- **[行业常识]** —— 滤清器行业通用做法、公开共识，不受某一家厂商约束；
- **[框架参考]** —— 认证 / 准入 / 合规框架介绍（EAC / GCC / INMETRO / CE / REACH / RoHS 等），**仅作常识框架，不构成认证或法律结论**；
- **[数据引用]** —— 引用 [data.hycarfilter](https://data.hycarfilter.com) canonical 数据集同值（HS 编码 / 效率档位 / 认证字段等）；
- **[分析判断]** —— 研究员原创主观判断，署名「小筑 ✍️」，供采购决策参考。

> **估算性数据**：市场规模区间、增速等为**估算参考（for reference only）**，非权威统计值，仅供量级参考，不作投资/采购定价依据。

## 数据一致性声明

本仓引用的一切 **HS 编码 / 效率档位 / 认证字段 / 品类划分** 均与 [data.hycarfilter](https://data.hycarfilter.com) 的 canonical 数据集 `data/products.json`（v0.1.0）同值；任何产品数值以 data 站为唯一事实源。本仓只负责「行业与市场知识」，不重复存储产品数值。
